# AI Compass

**AI Compass — сервис для выбора AI-инструментов под свои задачи и бюджет.**

Вместо поиска и сравнения десятков нейросетей пользователь выбирает свои цели и получает подходящие варианты с ценами, возможностями и ссылками на источники.

В каталоге — **23 AI-сервиса**, включая ChatGPT, Claude, Gemini, DeepSeek, Cursor, Higgsfield и другие.

## Попробовать AI Compass

Ссылка на работающий сайт предоставляется жюри отдельно по email.

**Ничего скачивать или устанавливать не нужно.** Просто откройте ссылку в браузере.

### Как пользоваться

1. Выберите роль — например, **«Студент + код»**.
2. Отметьте нужные задачи: программирование, учёба, презентации и другие.
3. Укажите месячный бюджет.
4. Сравните предложенные AI-инструменты, цены и возможности.

Результаты обновляются сразу. Регистрация не требуется.

## Возможности

- Подбор AI-инструментов по нескольким задачам.
- Каталог из 23 AI-сервисов.
- Сравнение бесплатных и платных тарифов.
- Отображение опубликованных цен и источников.
- Дополнительный режим точного подбора.
- Сохранение профилей и анализ расходов на подписки.

## Локальный запуск

Если вы хотите запустить проект на своём компьютере, потребуется Linux (x86-64), Git, Python 3.12+, Docker с Compose и интернет для первой установки.

```bash
git clone https://github.com/namantai/businesscup.git
cd businesscup
bash run.sh
```

После запуска откройте:

**http://127.0.0.1:5173**

Чтобы остановить приложение:

```bash
bash scripts/dev-down.sh
```

## Важно

AI Compass показывает опубликованные цены, которые могут отличаться от окончательной стоимости покупки в вашей стране.

Быстрый подбор основан на подтверждённых возможностях сервисов, а не на независимом тестировании качества моделей. Проект представлен как MVP.
