# AI Compass

**AI Compass помогает выбрать нейросети под задачи и бюджет.** Можно отметить сразу несколько целей — учёба, программирование, презентации, видео — и сравнить подходящие AI-сервисы, бесплатные и платные тарифы. На сайте есть каталог из **23 продуктов**, включая ChatGPT, Claude, Gemini, Cursor и Higgsfield.

## Быстрый запуск

**Нужен компьютер с Linux (x86-64)**, интернет для первого запуска, [Git](https://git-scm.com/), Python 3.12+ и **[Docker Engine с Docker Compose](https://docs.docker.com/engine/install/)**. Docker должен быть запущен. Java и Node.js устанавливать отдельно не требуется — проект подготовит их в своей папке.

Откройте терминал и выполните:

```bash
git clone https://github.com/namantai/businesscup.git
cd businesscup
bash run.sh
```

Когда появится сообщение **«AI Compass запущен»**, откройте **http://127.0.0.1:5173/**.

При первом запуске скрипт соберёт приложение, запустит PostgreSQL через Docker и загрузит проверенный каталог, если база пустая. При следующих запусках достаточно снова выполнить `bash run.sh`. Существующие данные не удаляются.

Чтобы остановить проект:

```bash
bash scripts/dev-down.sh
```

## Как попробовать

1. На главной выберите **«Студент + код»** или другую роль.
2. Отметьте несколько целей и введите бюджет, например **20 USD в месяц**.
3. Посмотрите подходящие AI-инструменты, их опубликованные цены и ссылки на источники. Выбор обновляется сразу, без регистрации.

В разделе **«Каталог»** можно посмотреть все 23 продукта. **«Точный подбор»** — дополнительный режим с подробными ограничениями и расчётом расходов.

## Как это устроено

**React + TypeScript** — интерфейс, **Java + Spring Boot** — сервер и подбор, **PostgreSQL** — каталог и пользовательские данные. **Docker используется только для запуска PostgreSQL.**

**Важно:** проект работает локально; цены — опубликованные предложения с указанием страны и источника, а не гарантия итоговой оплаты в Казахстане. Быстрый подбор сравнивает подтверждённые функции, но не оценивает качество моделей независимыми тестами. Платежи и платные AI API не нужны.

Если запуск не удался, проверьте `docker info` и файл `.runtime/jury-run.log`. Подробности и демонстрационные сценарии — в [руководстве](docs/DEMO_GUIDE.md).
